# Hidden

Secret ladders and traps that look just like common nodes such as
stone, wood, etc., but allow the player to walk through them as if
they were air.

Ladders allow the player to climb just like normal wooden ladders,
while traps are completely fall-through, just like air.

All secret nodes are rendered glass-like, so that they appear
completely transparent from the inside. Besides making sense, it also
sidesteps the x-ray glitch.

This mod is inspired by nanepiwo's *hiddendoors*, but is a near-complete
rewrite and is not backward compatible.
